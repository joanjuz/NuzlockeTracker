Fuentes para OBS

Las tres filas son independientes: podrás mover sprites, motes y barras donde quieras. También puedes usar un único Pokémon por fuente.

Dirección para las fuentes

El acceso remoto está apagado.

Usa la IP de tu propia computadora en Radmin VPN, no la del compañero. Solo se compartirán sprites, motes y PS. No abre los controles del tracker.

Composición y sprites

Se copian a tu carpeta local sprites_personalizados y se actualizan en OBS automáticamente.

Formatos admitidos en sprites_personalizados: PNG, APNG, GIF, WebP (también animado), JPG y BMP. Nombres como 25.png, 025.webp, pikachu.gif, 37-alola.png y 25-shiny.png. Los archivos se actualizan automáticamente; las imágenes grandes no se reducen antes de mostrarse en OBS.

Para una Fuente de navegador en OBS configura un ancho y alto suficientes para la escala seleccionada, p. ej. 1920 × 1080 al usar 2×. El texto y las barras se renderizan directamente en Chromium a esa escala, no como pequeñas imágenes estiradas.

Motes y tipografía

Barras de vida

Puedes usar PNG transparentes propios para el marco y el relleno. El relleno se recorta con el porcentaje real de PS sin estirar la imagen. Máximo 8 MB por PNG; hasta 4096 × 1024 píxeles.

Personalización

Los cambios se guardan automáticamente. Para ver el resultado, agrega los enlaces como Fuente de navegador en OBS. El modo local funciona mientras Pokémon Tracker esté abierto; para compartir usa la IP VPN.
