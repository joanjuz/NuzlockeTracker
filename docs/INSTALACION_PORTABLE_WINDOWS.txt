PROGRESSIVE TRACKER v1.4.0 - GUIA DE INICIO (WINDOWS)

CANDIDATO LOCAL: pendiente de autorizacion de publicacion. No se ha creado
una release ni una etiqueta definitiva como parte de esta preparacion.

DESCARGAR
1. Descarga PokemonTracker-Windows-x64.zip desde:
   https://github.com/joanjuz/NuzlockeTracker/releases/latest
2. Extrae el contenido en una carpeta nueva.
3. Abre PokemonTracker.exe con doble clic (Windows 10/11 de 64 bits).
   No requiere instalar Python, Node.js ni abrir una consola.
4. La interfaz utiliza Microsoft Edge WebView2 Runtime.
5. La primera ejecucion puede tardar unos segundos adicionales mientras
   el EXE portable extrae sus recursos temporales.

CONECTAR UN JUEGO
1. Inicia Lime3DS y carga una partida compatible:
   Ultra Sol, Ultra Luna, X, Y, Rubi Omega o Zafiro Alfa (version 1.0).
2. Abre la pestaña Conexion del tracker, elige el juego y su proceso (PID).
3. Conecta y comprueba el equipo. Las cajas se actualizan automaticamente.
4. Si Gen6 no localiza el equipo, prueba reiniciar el JUEGO dentro del
   emulador; la reconexion en algunas situaciones sigue en investigacion.
5. Azahar/Citra y otras versiones de juegos no estan validadas por completo.

OBS
1. Abre el editor OBS dentro de Progressive Tracker.
2. Copia las URL locales de sprites, motes, PS, muertes/vidas o composicion.
3. Pegalas en OBS Studio como Fuente de navegador, con fondo transparente.
4. Puedes importar sprites PNG, APNG, GIF o WebP personalizados desde
   el editor, o utilizar la carpeta sprites_personalizados.
5. Ajusta escala, fuentes y barras, y verifica el resultado en OBS.
   Mantiene abierto el tracker mientras transmites.

DATOS DE DEFINITIVE RANDOMIZER (ULTRA SOL / ULTRA LUNA)
1. Guarda los cambios en Randomizer y exporta datos para Progressive Tracker.
2. Abre la partida correcta del Tracker y selecciona el juego en Conexion.
3. Selecciona el JSON en Datos de Definitive Randomizer y previsualiza.
4. Revisa diferencias; confirma el aviso si la revision es desconocida.
5. Confirma la importacion. Se conserva al cerrar y reabrir esa partida.
6. Reemplazar o retirar la importacion no modifica ROM, guardado ni RAM.
   Los valores vivos siguen viniendo del emulador. No incluye DS/Switch.

LIMITES DE NIVEL Y LISTAS DE ETAPAS
1. Abre Progreso y anade las etapas de tu aventura con su nivel maximo.
   Pulsa Guardar cambios para aplicarlas; Descartar deja la lista como estaba.
2. Elige la etapa vigente. El Tracker avisa cuando un Pokemon del equipo
   supera el limite; es solo informativo y no incluye limites oficiales.
3. Exportar lista guarda las etapas en un JSON (solo nombres, niveles y orden)
   y Importar lista carga uno con vista previa. Al reemplazar una lista
   existente se pide confirmacion y no se elige ninguna etapa vigente.
4. Cada partida y cada juego guardan sus propias etapas.

PERFILES, RESPALDOS Y ACTUALIZACIONES
- Tu progreso y preferencias se guardan normalmente en:
  %LOCALAPPDATA%\PokemonTracker\runtime
- Antes de actualizar: cierra el tracker y respalda esa carpeta.
- Para actualizar: extrae la nueva descarga en OTRA carpeta y ejecuta
  el nuevo EXE. No reemplaces archivos mientras el programa este abierto.
- Es portable y no incluye instalador ni desinstalador.
- En dos instancias, comprueba el PID correcto de cada emulador.
- La barra Partida permite crear, abrir y eliminar perfiles independientes.
- Para eliminar la partida actual, abre otra primero. Principal se conserva.
- Soul Link permite conexion directa con un tracker como host en LAN/VPN;
  Cloudflare sigue disponible como alternativa. Ambos admiten los seis juegos.
- Ninguna muerte remota mata automaticamente al Pokemon local.
- El ZIP no contiene ROMs, partidas, credenciales ni tokens privados.

DIAGNOSTICO
- Si la ventana falla, instala o repara WebView2 Runtime y revisa:
  %LOCALAPPDATA%\PokemonTracker\desktop-error.log
- Si Windows SmartScreen muestra una advertencia, verifica que la descarga
  proceda del release oficial. El programa no esta firmado digitalmente.
- El tracker no altera la RAM ni la ROM; solo efectua lecturas.
- Algunas funciones de OBS HD aun requieren validacion visual final.
