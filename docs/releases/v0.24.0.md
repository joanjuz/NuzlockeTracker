# Progressive Tracker v0.24.0 — primera distribución pública para Windows

Esta versión reúne las funcionalidades ya integradas en `master` hasta los PR #14 (Gen6 y Living Dex) y #15 (mejoras gráficas OBS HD), en un ejecutable portable para **Windows 10/11 de 64 bits**.

## Descarga e instalación

1. En **Assets**, descarga **`PokemonTracker-Windows-x64.zip`** (no el código fuente automático de GitHub).
2. Extrae el ZIP en una carpeta nueva y abre **`PokemonTracker.exe`**.
3. Abre **Lime3DS** con el juego compatible; desde **Conexión**, selecciona el título y el proceso del emulador.
4. El programa guarda el progreso en `%LOCALAPPDATA%\PokemonTracker\runtime`. Antes de actualizar, haz una copia de seguridad de esa carpeta.
5. Para las fuentes de OBS, abre el editor OBS del tracker y copia las URL de las capas deseadas.

**No requiere instalar Python ni Node.js.** Windows necesita Microsoft Edge WebView2 Runtime. El ejecutable **no está firmado digitalmente**, por lo que SmartScreen puede solicitar confirmación: verifica siempre el origen antes de ejecutar.

## Funcionalidades incluidas

- **Gen7:** Ultra Sol 1.0 y Ultra Luna 1.0.
- **Gen6:** Pokémon X 1.0, Y 1.0, Rubí Omega 1.0 y Zafiro Alfa 1.0.
- Consulta de equipo, cajas, PS durante combate y progreso de rutas; lectura de PC automática (31 cajas Gen6, 32 cajas Gen7).
- Living Dex por Pokédex Nacional, con especies ausentes como Poké Ball o sprites en escala de grises, y consultas de datos guardados y del compañero.
- Registro Nuzlocke: capturas, MISS, muertes, revivir, fósiles, regalos, huevos e intercambios.
- Análisis ofensivo/defensivo y plantillas CSV informativas de **pk3DS Progressive**.
- **Soul Link Companion** opcional mediante Cloudflare Worker + D1 y sincronización de estados; las muertes de pareja **requieren confirmación manual**.
- **OBS:** seis posiciones independientes de sprites, motes y barras de PS, capas transparentes, fuentes importadas y barras configurables.
- **OBS HD:** PNG de alta calidad, GIF y WebP animados, sprites personalizados importables por lotes, interpolación de PS y escala 1× a 4×.

## Compatibilidad y limitaciones

El funcionamiento básico de equipo, cajas y PS fue validado en **Lime3DS** para los seis juegos indicados. **Azahar/Citra, ROM modificadas, Soul Link Gen6 y escenarios de combate especiales no cuentan con garantía de compatibilidad completa**.

Las mejoras OBS HD están implementadas y cubiertas por pruebas automatizadas, pero todavía se recomienda comprobar su calidad visual final en una escena real de OBS. En algunos arranques de Gen6 el rastreo de RAM puede requerir reiniciar el juego dentro de Lime3DS.

## Seguridad y distribución

- La aplicación **solo lee** la RAM del emulador; no modifica la ROM ni la partida.
- El ZIP no incluye ROM, guardados, tokens, claves ni configuraciones privadas.
- **`SHA256SUMS.txt`** contiene el hash SHA-256 del ZIP publicado, para verificar la integridad de la descarga.
- El paquete es **portable, no un instalador**: extrae el ZIP y ejecuta el EXE.
