# Progressive Tracker v1.1.0 — conjuntos de sprites, cementerio en OBS e iconos de objetos

Elige entre varios conjuntos de sprites para OBS, muestra a los caídos en una fuente de cementerio y usa iconos de objetos, propios o descargados, también en la ventana principal.

## Descarga

Descarga **PokemonTracker-Windows-x64.zip**, extráelo y abre **PokemonTracker.exe**. También se ofrece el EXE por separado. Windows 10/11 de 64 bits y Microsoft Edge WebView2 Runtime; no hace falta instalar Python ni Node.js.

Antes de actualizar, cierra el tracker y respalda `%LOCALAPPDATA%\PokemonTracker\runtime`. Las ROM y los guardados del emulador se conservan. Copia también tu carpeta `sprites_personalizados` junto al nuevo ejecutable si la usas.

## Novedades

- **Conjuntos de sprites:** cada subcarpeta de `sprites_personalizados` es un conjunto (por ejemplo `Home/` o `Smogon/`) que se elige en el editor OBS. Si a un conjunto le falta un Pokémon, se usa el de la carpeta principal y después el sprite normal. Al importar sprites se puede crear un conjunto nuevo. Las carpetas con miles de archivos se leen una sola vez hasta que cambian.
- **Cementerio en OBS:** nueva fuente `layer=graveyard` con los Pokémon caídos en gris, título con el total, columnas, tamaño, orden (recientes o antiguos primero) y mote, especie, nivel y ruta opcionales.
- **Iconos de objetos propios:** imágenes en `objetos/` (en la carpeta principal o dentro de un conjunto) nombradas por número, nombre en inglés o nombre en español: `234.png`, `leftovers.png` o `restos.png`. Admiten animación y se importan desde el editor.
- **Iconos de objetos en la ventana principal:** en las tarjetas del equipo y en la ficha de cada Pokémon.
- **Eliminar la Partida principal:** ahora se puede borrar como las demás cuando hay otra abierta. Solo se eliminan sus datos; el resto de partidas, el registro y la caché se conservan.
- **Aviso de nueva versión:** una vez al día se consulta la última versión publicada en GitHub y, si hay una nueva, se muestra un aviso con el enlace de descarga. Se puede ocultar y se desactiva con `POKEMON_TRACKER_NO_UPDATE_CHECK=1`.

## Correcciones y mantenimiento

- Al cambiar de conjunto, OBS actualiza los sprites del cementerio y los iconos sin recargar la fuente.
- El servidor local y la interfaz se reorganizaron en módulos más pequeños sin cambiar su comportamiento.
- Pruebas de navegador en cada cambio y firma del ejecutable preparada para SignPath.

## Validación y límites

Pruebas automatizadas de Python, interfaz JavaScript, navegador y Worker, junto con análisis estático. El EXE portable pasa la comprobación de API, recursos y carga de Python.NET/WinForms con datos aislados, y se probó con una partida real y conjuntos de sprites reales. `SHA256SUMS.txt` permite verificar los archivos publicados.

El ejecutable todavía no está firmado digitalmente, por lo que Windows SmartScreen puede mostrar un aviso la primera vez. La lectura de memoria es experimental en Azahar/Citra y en escenas de combate especiales. La aplicación solo lee RAM; no altera la ROM ni el guardado.
